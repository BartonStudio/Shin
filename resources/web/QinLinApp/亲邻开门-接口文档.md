# 亲邻开门接口文档

> 小区：富力桃园 D 区（`communityId=4222`）  
> 版本：App `5.2.1` / 文档日期 `2026-08-09`  
> 配套 Postman：`亲邻开门-D10门禁.postman_collection.json`  
> 配套脚本：`qinlin_login.py`、`qinlin_open_door.py`

完整链路只有 **3 个业务接口**（短信 → 登录 → 开门）。  
开门接口不变，只通过 `doorControlId` 区分三扇门。

```
发短信 ──► 填验证码登录 ──► 拿到 sessionId ──► 开门(选门)
gateway2      mobileapi3/login                mobileapi3/open
```

## 0. 公共约定

### 0.1 域名

| 用途 | Host |
|---|---|
| 短信 | `https://gateway2.qinlinkeji.com` |
| 登录 / 开门 | `https://mobileapi3.qinlinkeji.com` |

> **不要**用 `https://qapp.qinlinkeji.com/app/api/app/v1/login`。  
> 该路径会固定返回 `code=4 用户没有绑定`，不验短信，是错接口。

### 0.2 通用请求头

```http
user-agent: Dart/3.10 (dart:io)
qversioncode: 3141
qchannel: xiaomi
qplatform: 0
qvendor: OnePlus
content-type: application/json; charset=utf-8
accept-encoding: gzip
```

### 0.3 两套签名（不要混用）

| 场景 | 签名位置 | 盐/密钥 | 说明 |
|---|---|---|---|
| 发短信 | **请求头** | `appsecret=OKFoQ9MmNXQtcyXROo4PnaFkfDPTHuDg` | `Encryption.getHeaderSign` |
| 登录 / 开门 | **业务参数 sign 字段** | `key=qiAnlPinP` | `_QappEncrypt` / `onAsciiSort` |

共同规则：

1. 参与签名的字段全部转字符串
2. 按 **key 字典序** 拼成 `k=v&k=v...`
3. 末尾追加盐
4. `sign = MD5(raw).toUpperCase()`（32 位大写 hex）

### 0.4 关键常量

| 名称 | 值 |
|---|---|
| header appid | `gbDjIZQSOpCMX49P` |
| header appsecret | `OKFoQ9MmNXQtcyXROo4PnaFkfDPTHuDg` |
| body/query 签名盐 | `qiAnlPinP` |
| 手机号 AES key（hex） | `FBC213C4C7BEEBD2AA4EDBF0F681C41B`（32 hex = 16 字节 AES-128） |
| app 版本 | `5.2.1` |
| communityId | `4222` |

## 1. 发送短信验证码

### 基本信息

| 项 | 值 |
|---|---|
| Method | `POST` |
| URL | `https://gateway2.qinlinkeji.com/member/sms/sendSecurityCode` |
| Content-Type | `application/json; charset=utf-8` |
| 频率限制 | 每天最多约 5 次；60 秒重发；验证码约 5 分钟有效 |

### Body

```json
{
  "mobile": "18211576983"
}
```

仅此一个业务字段。

### 请求头签名（额外 5 个 header）

参与签名参数：

```
appid, mobile, nonce, timestamp, version
```

- `appid` = `gbDjIZQSOpCMX49P`（固定）
- `nonce` = 4 位数字（不足补零）
- `timestamp` = 毫秒时间戳
- `version` = `v2`（固定）
- `mobile` = 明文手机号

签名串：

```text
appid=...&mobile=...&nonce=...&timestamp=...&version=v2&appsecret=OKFoQ9MmNXQtcyXROo4PnaFkfDPTHuDg
sign = UPPER(MD5(签名串))
```

把这 5 个值放进 **header**（不是 query/body）：

```http
appid: gbDjIZQSOpCMX49P
nonce: 1234
timestamp: 1723200000000
version: v2
sign: A1B2C3...
```

### 成功响应（示意）

```json
{
  "code": 0,
  "message": "success",
  "data": null,
  "success": true
}
```

`code` 为 `0` 或 `200` 一般可视为成功。

### Python 参考

```python
import hashlib, random, time

appid = "gbDjIZQSOpCMX49P"
appsecret = "OKFoQ9MmNXQtcyXROo4PnaFkfDPTHuDg"
mobile = "18211576983"
h = {
    "appid": appid,
    "nonce": f"{random.randint(0, 9999):04d}",
    "timestamp": str(int(time.time() * 1000)),
    "version": "v2",
}
merged = {**h, "mobile": mobile}
raw = "&".join(f"{k}={merged[k]}" for k in sorted(merged)) + f"&appsecret={appsecret}"
h["sign"] = hashlib.md5(raw.encode()).hexdigest().upper()
# POST body={"mobile": mobile}, headers 追加 h
```

## 2. 手机号 + 验证码登录

### 基本信息

| 项 | 值 |
|---|---|
| Method | `POST` |
| URL | `https://mobileapi3.qinlinkeji.com/api/app/v1/login` |
| Content-Type | `application/json; charset=utf-8` |
| 产出 | `sessionId`（形如 `app:` + 32 位 hex） |

### Body 业务字段

| 字段 | 说明 |
|---|---|
| `mobile` | **AES 加密后的大写 hex**，不是明文 |
| `smsCode` | 短信验证码明文 |
| `appChannel` | 固定 `2` |

再注入固定签名字段：

| 字段 | 说明 |
|---|---|
| `timestamp` | 毫秒时间戳 |
| `version` | `5.2.1` |
| `nonce` | 5 位数字（不足补零） |
| `sign` | body 签名（见下） |

> 未登录状态 **不传 token**。

### mobile 加密规则

- 算法：`AES-128-ECB` + `PKCS5/PKCS7`
- key：把 `FBC213C4C7BEEBD2AA4EDBF0F681C41B` **按 hex 解码成 16 字节**
- 输出：密文的 **大写 hex 字符串**（不是 Base64）

等价于官方 Flutter 插件 `flutter_aes_ecb_pkcs5.encryptString`。

### body 签名规则

对业务+固定字段整表签名（**不含** 即将写入的 `sign` 自身以外的最终字段集：先放齐再算 sign）：

```text
appChannel=2&mobile=<AES大写hex>&nonce=<5位>&smsCode=<验证码>&timestamp=<ms>&version=5.2.1&key=qiAnlPinP
sign = UPPER(MD5(签名串))
```

注意：所有 value 以字符串参与拼接（`appChannel` 即使 JSON 里是数字，签名时也是 `"2"`）。

### 请求示例（字段示意）

```json
{
  "mobile": "A1B2C3D4....", 
  "smsCode": "123456",
  "appChannel": 2,
  "timestamp": "1723200000000",
  "version": "5.2.1",
  "nonce": "01234",
  "sign": "DEADBEEF..."
}
```

### 成功响应（示意）

响应里会出现 `app:xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`。  
常见位置：`data.sessionId` / `data.token` / 或文本中直接匹配。

拿到后保存为 `sessionId`，后续开门都靠它。

### 常见失败

| 现象 | 原因 |
|---|---|
| `验证码错误` / `验证码过期` | 短信过期、填错；或接口是对的 |
| `签名时间戳不能为空` / `签名不能为空` / `code=121` | body 漏了 timestamp/nonce/version/sign |
| `用户没有绑定` / `code=4` | **走错了 qapp 登录路径**，改回 mobileapi3 |

### Python 参考（核心）

```python
import hashlib, random, time
from Crypto.Cipher import AES  # pip install pycryptodome

def aes_ecb_hex(plain: str) -> str:
    key = bytes.fromhex("FBC213C4C7BEEBD2AA4EDBF0F681C41B")
    data = plain.encode()
    pad = 16 - len(data) % 16
    data += bytes([pad]) * pad
    return AES.new(key, AES.MODE_ECB).encrypt(data).hex().upper()

def qapp_body_sign(biz: dict) -> dict:
    body = dict(biz)
    body["timestamp"] = str(int(time.time() * 1000))
    body["version"] = "5.2.1"
    body["nonce"] = f"{random.randint(0, 99999):05d}"
    sign_map = {k: str(v) for k, v in body.items()}
    raw = "&".join(f"{k}={sign_map[k]}" for k in sorted(sign_map)) + "&key=qiAnlPinP"
    body["sign"] = hashlib.md5(raw.encode()).hexdigest().upper()
    return body

body = qapp_body_sign({
    "mobile": aes_ecb_hex("18211576983"),
    "smsCode": "123456",
    "appChannel": 2,
})
# POST https://mobileapi3.qinlinkeji.com/api/app/v1/login
```

## 3. 开门（一接口三门）

### 基本信息

| 项 | 值 |
|---|---|
| Method | `POST` |
| URL | `https://mobileapi3.qinlinkeji.com/api/open/doorcontrol/v2/open` |
| Body | 无（空 body / content-length 可为 0） |
| 参数位置 | **Query** |

三扇门共用这一个接口，只改 `doorControlId`。

### 门编号对照

| 代号（脚本） | doorControlId | 名称 |
|---|---|---|
| 1 | `16708` | D10 大堂门 |
| 2 | `16709` | D10 负一 / 地库门 |
| 3 | `16671` | D12 手动推拉门 |

小区固定：`communityId=4222`。

### Query 参数

| 参数 | 示例 | 说明 |
|---|---|---|
| `sessionId` | `app:8a8181...` | 登录态；URL 里叫 sessionId |
| `appChannel` | `1` | 开门固定 1 |
| `doorControlId` | `16708` | 选门 |
| `communityId` | `4222` | 小区 |
| `timestamp` | 毫秒时间戳 | 约 10~15 分钟有效窗口 |
| `version` | `5.2.1` | |
| `nonce` | 5 位数字 | 不足补零 |
| `sign` | 32 位大写 MD5 | 见下 |

### 开门签名（重点）

签名时使用字段名 **`token`**，值 = `sessionId` 同值；  
但 **URL 上不出现 `token` 参数**，token 只参与签名计算。

签名串：

```text
appChannel=1&communityId=4222&doorControlId=16708&nonce=01234&timestamp=1723200000000&token=app:xxxx&version=5.2.1&key=qiAnlPinP
sign = UPPER(MD5(签名串))
```

### 请求示例

```http
POST /api/open/doorcontrol/v2/open?sessionId=app:xxxx&appChannel=1&doorControlId=16708&communityId=4222&timestamp=1723200000000&version=5.2.1&nonce=01234&sign=ABCD... HTTP/1.1
Host: mobileapi3.qinlinkeji.com
user-agent: Dart/3.10 (dart:io)
qversioncode: 3141
qchannel: xiaomi
qplatform: 0
qvendor: OnePlus
content-type: application/json; charset=utf-8
```

### 成功响应

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "authType": 2,
    "communityId": 4222,
    "communityName": "富力桃园D区",
    "hasToAudited": 0,
    "managerMobile": "02037788680",
    "openDoorState": 1
  }
}
```

判定标准：

- **真正开门成功**：`code == 0` 且 `data.openDoorState == 1`
- 仅有 `code == 0` 不够。例如 sign 不对时可能仍 `code:0`，但 `openDoorState:6`，**门不会开**

### 常见失败

| 现象 | 处理 |
|---|---|
| `401` / `您还没有登录` | sessionId 失效，重跑短信+登录 |
| `openDoorState != 1` | 检查 sign / timestamp 窗口 / 门 id |
| 超时或网络错 | 重试；无线 ADB 场景与接口无关 |

### Python 参考

```python
import hashlib, time, random, urllib.parse, urllib.request

def open_door(session_id: str, door_control_id: str, community_id: str = "4222"):
    ts = str(int(time.time() * 1000))
    nonce = f"{random.randint(0, 99999):05d}"
    sign_raw = (
        f"appChannel=1&communityId={community_id}&doorControlId={door_control_id}"
        f"&nonce={nonce}&timestamp={ts}&token={session_id}&version=5.2.1&key=qiAnlPinP"
    )
    sign = hashlib.md5(sign_raw.encode()).hexdigest().upper()
    q = urllib.parse.urlencode({
        "sessionId": session_id,
        "appChannel": "1",
        "doorControlId": door_control_id,
        "communityId": community_id,
        "timestamp": ts,
        "version": "5.2.1",
        "nonce": nonce,
        "sign": sign,
    })
    url = f"https://mobileapi3.qinlinkeji.com/api/open/doorcontrol/v2/open?{q}"
    req = urllib.request.Request(url, method="POST", data=b"", headers={
        "user-agent": "Dart/3.10 (dart:io)",
        "qversioncode": "3141",
        "qchannel": "xiaomi",
        "qplatform": "0",
        "qvendor": "OnePlus",
        "content-type": "application/json; charset=utf-8",
    })
    return urllib.request.urlopen(req, timeout=12).read().decode()

# open_door("app:....", "16708")  # 大堂
# open_door("app:....", "16709")  # 地库
# open_door("app:....", "16671")  # 推拉
```

## 4. 推荐调用顺序

1. **发送短信** → 等手机收到验证码  
2. **登录** → 解析并保存 `sessionId`  
3. **开门** → 选 `doorControlId`（16708 / 16709 / 16671）  
4. session 失效（约会过期或被多端踢）→ 回到第 1 步  

Postman 已内置自动签名：

1. 设 collection 变量 `mobile`
2. 跑「登录-获取短信验证码」
3. 填 `smsCode`
4. 跑「登录-手机号验证码」（成功自动写回 `sessionId`）
5. 跑三扇门任意一个

CLI：

```bash
python qinlin_login.py 18211576983
python qinlin_open_door.py app:你的sessionId 1   # 1大堂 2地库 3推拉
```
